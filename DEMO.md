# 2-minute live demo script

## Prep (once)
1. `START.bat` (bridge + localhost)
2. Chrome extension loaded (`extension/` unpacked), bridge online in popup
3. OpenRouter key saved (Key button)
4. Optional: Classroom signed in with Grade 5 Space Quiz
5. Open http://localhost:8124 — hard refresh
6. Click **DEMO** (bottom bar) before you start talking

## Spoken flow (~2:00)

| t | You say | Expect |
|---|---|---|
| 0:00 | *(after Demo on)* **Hi, how are you?** | Fast friendly reply |
| 0:15 | **Go into Google Classroom and check my next assignment** | In-page panel animates + Space Quiz (live GC and/or demo pack) spoken |
| 0:45 | **Class mode** | Camera + mic on, short confirm |
| 1:00 | **Revision mode — explain last week’s biology** | Plant parts taught blind-pedagogy style |
| 1:30 | **Quiz mode** | Space questions |
| 1:50 | **Save answers** *(if assignment)* | File download |

Also works: interrupt anytime by speaking; **Data** exports telemetry JSON.

## Buttons
- **DEMO** — Maya / Grade 5 / Space quiz / last-week plants memory
- Camera · Upload · Data · Key
